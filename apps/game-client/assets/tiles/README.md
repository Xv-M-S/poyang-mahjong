# Mahjong tile artwork

The 34 tile-face PNG files in this directory are resized exports from
[FluffyStuff/riichi-mahjong-tiles](https://github.com/FluffyStuff/riichi-mahjong-tiles).

The upstream project releases all artwork under the Creative Commons Zero
v1.0 Universal dedication (CC0-1.0 / public domain).

Kind mapping:
- 0-8: Man1-Man9 (characters / 万)
- 9-17: Pin1-Pin9 (circles / 筒)
- 18-26: Sou1-Sou9 (bamboos / 条)
- 27-33: Ton, Nan, Shaa, Pei, Chun, Hatsu, Haku

Local changes: resized from 600x800 to 150x200 PNG for the WeChat Mini Program package.

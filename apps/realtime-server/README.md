# Realtime Server

鄱阳麻将实时房间服务的第一版实现。

## 当前能力

- WebSocket 连接；
- 内存房间仓库；
- 六位房间号；
- 创建房间、加入房间、准备和开局；
- 房间级乐观版本；
- `requestId` 幂等缓存；
- 摸牌、出牌和吃碰杠胡命令路由；
- 公开房间快照；
- 按玩家发送的私有手牌快照；
- 单局引擎和多局比赛引擎接入。

## 开发启动

在仓库根目录执行：

```bash
npm run start:realtime
```

默认监听：

```text
ws://127.0.0.1:8080?userId=<development-user-id>
```

也可以设置 `HOST` 和 `PORT`。

## 开发身份说明

当前 `userId` 从 WebSocket 查询参数读取，仅用于本地联调。正式环境必须替换成 API 服务签发的短期连接票据，不能相信客户端自行提交的用户 ID。

## 当前存储说明

房间和幂等记录都保存在进程内存中。服务重启后数据会丢失。下一阶段将通过接口加入 Redis、PostgreSQL、事件存储和快照恢复。

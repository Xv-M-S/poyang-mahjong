# 鄱阳麻将规则基线 v1

> 来源：工作区 `rule` 目录中的 8 张规则图片及其整理稿。  
> 状态：开发基线，不是最终计分约定。

## 已确认并进入代码的规则

1. 普通“四副面子加一对将”的平胡结构不能单独胡牌。
2. 手牌必须先满足基础胡牌结构，再至少满足一种鄱阳认可牌型。
3. 第一批实现断断、碰碰胡、一条龙、七对、清一色、混一色、全字、十三幺和绿一色。
4. 牌型允许复合识别，计分叠加方式留待确认。

## 已记录、尚未编码的牌型

- 国乱（普乱）与国乱七字全；
- 乱幺及暗杠是否破坏门清；
- 三板同；
- 板胶与轮胡；
- 四归三、四归四；
- 大板板、小板板；
- 十八罗汉。

这些牌型需要进一步确认精确定义、拆牌方式和边界案例后再进入规则引擎。

## 待确认的对局与计分规则

- 使用的完整牌集；
- 庄家、连庄与换庄；
- 吃牌限制；
- 杠分和抢杠胡；
- 一炮多响及过胡；
- 各牌型番数、叠加、互斥与封顶；
- 自摸、点炮、杠上花和海底；
- 底分、包赔、流局；
- 超时、托管、离线和房间解散。

代码中的 `POYANG_RULES_V1` 对未确认项目使用 `null`，避免用猜测代替规则。

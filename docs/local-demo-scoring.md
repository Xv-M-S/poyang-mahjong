# 单机演示计分配置

> 状态：仅用于小程序单机闭环验证，不代表最终鄱阳麻将正式计分。

## 比赛规则

- 每场 4 局；
- 庄家胡牌或流局时连庄，否则庄家顺时针轮换；
- 允许一炮多响；
- 玩家放弃可胡操作后，在自己下一次摸牌前不能再次胡牌；
- 四家累计分数始终保持零和。

## 演示番数

| 牌型 | 番数 |
|---|---:|
| 断幺 | 1 |
| 碰碰胡 | 2 |
| 一条龙 | 2 |
| 七对 | 2 |
| 清一色 | 3 |
| 混一色 | 2 |
| 字一色 | 4 |
| 十三幺 | 4 |
| 绿一色 | 4 |
| 杠上开花 | 1 |
| 海底捞月 / 河底捞鱼 | 1 |
| 抢杠胡 | 1 |
| 自摸附加 | 1 |

底分为 1，按 `底分 × 2^番数` 计算，最高 4 番，单次支付上限 16。点炮支付倍率为 3；庄家参与支付时倍率为 2。

## 演示杠分

- 暗杠：其余三家各支付 2 分；
- 明杠：出牌者支付 3 分；
- 补杠：其余三家各支付 1 分；
- 抢杠胡发生时补杠不成立，也不产生补杠分。

正式规则确认后，应只替换配置和黄金用例，不改变比赛状态机结构。
